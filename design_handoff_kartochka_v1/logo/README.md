# Logo — Seedling

Brand glyph for Kartochka. Built from a single shared path; everything else is a
recolour or different background.

## Masters
- `icon-master.svg` — 232² viewBox, 51 radius, teal bg, white seedling, amber bud.
- `icon-master-no-radius.svg` — 232² viewBox, square, OS-handled rounding (use this for app icon submissions; iOS / Android apply their own corner mask).
- `monogram.svg` — transparent bg, teal seedling. For favicons + small tabs.
- `monogram-white.svg` — transparent bg, white seedling. For dark surfaces.

## Wordmark
- `wordmark-ru.svg` — "Карточка" (primary launch)
- `wordmark-en.svg` — "Kartochka"
- `wordmark-ar.svg` — "كارتوشكا"
- `wordmark-ru-dark.svg` — wordmark on the dark slate background, for splash variants.

## Raster (iOS app icon set)
PNG at: 1024, 512, 180, 167, 152, 120, 87, 80, 76, 60, 58, 40, 29, 20.
Use `icon-1024.png` as the App Store master.

## Android adaptive icon
- `android-adaptive-foreground.svg` (+ .png) — 432² with the seedling sized to fit
  Android's 60% safe zone.
- `android-adaptive-background.txt` — the solid colour to use for the bg layer (#2A7F7F).

## Don'ts
- No pink, no powder blue.
- No human/child imagery alongside the mark.
- Don't recolour the amber bud — it's the only warm note in the system.
- Don't stretch the wordmark; the mark + word ratio is fixed in the SVG.
